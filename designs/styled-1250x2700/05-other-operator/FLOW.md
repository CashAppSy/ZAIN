# Number from Another Operator

Sign in -> backend number validation -> error -> edit number -> retry validation.

No SMS is sent for rejected numbers. No automatic transition to Home.

Number-not-found means absent from subscriber records, not malformed input. Operator membership must be determined by authoritative backend data, not the prefix. Google authentication does not bypass subscriber eligibility. The displayed +963 944 222 111 is a formatting example reused across hypothetical states.
