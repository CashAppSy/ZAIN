# Styled screens — 1250 x 2700

Latest-reference visual design: a blue-gradient Home header, clean white authentication screens without a blue header banner, rounded cyan buttons, blue-gradient current-plan card, quick-action icons and bottom navigation with a central purple ZAIN button. Rejected-number cases use a modal over the dimmed sign-in screen. Screen copy is English; phone format is +963 944 222 111.

All 30 individual PNG screens have been verified at exactly **1250 x 2700 pixels**. SVG and PDF use the same portrait ratio. Five flow boards show the same-size phones, numbered steps, arrows and captions.

Folders cover mobile login, Google, automatic network login, number not found and other operator. Linking a number after Google is conditional. Automatic verification occurs during Splash. Error cases never send SMS or open Home before number validation succeeds. Operator eligibility requires backend data. Google provider UI is illustrative; account and package values are sample data.

Earlier wireframe versions remain in their original folders. This is the current styled version. The splash follows the supplied metallic ZAIN / Middle East map artwork. Loading states use a 24-design-pixel spinner, 900 ms linear rotation and contextual labels. Buttons and duplicate submission are disabled while requests are pending. Animated SVGs and loading-demo.html show the motion; PNG/PDF are static snapshots.
